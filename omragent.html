🖨️

양식 자동 인식 (템플릿 등록)

빈 결의서 양식 PDF 업로드만으로 표 구조와 기표 원 위치를 자동 감지. 망점 인쇄 스캔은 검증된 원 감지 방식으로 자동 전환.

표 구조 분석 감지 확인 이미지 수동 편집기
🔍

OMR 자동 판독

배경 밝기 대비 상대 임계값 방식으로 마킹 여부를 판정 — 스캐너별·페이지별 밝기 편차에 강건. 찬성·반대·기권·무효 자동 분류.

채움 비율 분석 밝기 편차 대응
🗳️

3가지 안건 유형 지원

찬성/반대 2지, N지선다(복수 마킹 = 무효), 선거형 후보 다중선택(최대 선출 인원 검증)까지 한 양식 안에서 혼합 지원.

찬반 N지선다 후보 다중선택
🏆

득표 순위·당선권 산출

선거 안건은 후보별 득표수를 표준경쟁순위로 정렬 — 동점자는 같은 등수, 다음 등수는 인원만큼 밀림. 당선 정원 이내 후보는 '당선권' 표시.

동점 동순위 당선권 강조
🧐

검토 필요 자동 선별

채움 비율이 경계값 근처인 모호한 마킹만 '검토 필요'로 분류해 원본 PDF와 함께 별도 폴더에 격리. 전수 재검표가 필요 없습니다.

review 폴더 원본 즉시 열람
✏️

인라인 보정 + 감사 추적

대시보드에서 드롭다운으로 결과를 직접 수정 — 즉시 집계·Excel에 반영. 최초 수정 시 원본 판정과 수정 시각을 보존해 감사 추적 가능.

원본 판정 보존 수정 이력
📊

실시간 집계 대시보드

안건별 찬성·반대·기권·무효·검토 필요 건수와 비율, 분포 막대를 한 화면에. 집계 셀 클릭으로 해당 폴더가 탐색기에 바로 열립니다.

건수+비율 표기 셀 클릭 폴더 열기
📑

Excel 보고서 2종

안건별 집계 Excel + PDF별 원시데이터 Excel. 원시데이터의 하단 집계는 수식 기반 — 셀 값을 고치면 집계가 즉시 자동 갱신됩니다.

집계 Excel 원시데이터 수식 자동 갱신
🔤

안건 제목 자동 추출 (OCR)

양식 PDF의 내장 텍스트를 우선 추출하고, 이미지 스캔은 한국어 AI OCR로 폴백. 잘못 읽힌 제목은 표에서 클릭 한 번으로 수정.

1

기울기 보정

표선 각도 기반 하이브리드 보정으로 스캔 기울기를 정렬.

잡는 오차: 스캔 시 용지 기울어짐 (±5°)
실패 시: 보정 보류 — 원본 유지
2

전역 좌표 정렬

인쇄된 기표 원을 감지해 양식 템플릿과 매칭 — 회전·배율·이동을 일괄 보정.

잡는 오차: 망점 인쇄 스캔의 잔류 회전 2~3°
실패 시: 항등변환으로 안전 복귀
3

국소 재정렬

측정 직전 각 기표 원의 실제 중심을 ±25px 범위에서 재탐색.

잡는 오차: 행마다 다른 국소 어긋남 (±17px)
실패 시: 원본 좌표 사용
4

상대 임계값 측정

주변 배경 밝기 대비 채움 비율로 마킹 여부 판정.

잡는 오차: 페이지별 스캔 밝기 편차

✅ 유효 정상 마킹 1~M명 — 마킹된 후보 전원 득표 카운트 (M명 미만 선택도 유효)

집계는 유효 결의서의 선택만 후보별 득표로 카운트하며, 무효 결의서의 마킹은 전부 제외됩니다. 득표 순위 표는 동점자를 같은 등수로 표기하고(1, 2, 2, 4…), 당선 정원 이내 후보를 '당선권'으로 강조합니다.
활용 시나리오

서면 개표가 있는 곳이라면
어디든 적용됩니다

01

총회 서면결의서 집계

도시정비법 §45 · 서면 의결권 행사

정기·임시총회 서면결의서 수백~수천 장을 당일 판독·집계. 안건별 찬성·반대·기권·무효 건수와 비율을 즉시 산출합니다.

02

조합 임원·대의원 선거

후보 다중선택 · 득표 순위 자동 산출

후보 N명 중 최대 M명 선출 양식을 그대로 판독. 초과 마킹 무효 처리, 득표 순위와 당선권까지 자동으로 표시합니다.

03

시공자 선정 총회

도시정비법 §29 · N지선다 안건

복수 후보 중 1개 선택 안건을 지원 — 2개 이상 마킹은 무효로 자동 분류. 후보별 득표 chip으로 결과를 한눈에 확인합니다.

04

동의서 징구 집계

도시정비법 §35·§36 · 서면 동의

조합설립·사업시행 동의서의 동의 여부 마킹을 일괄 판독. 회수분을 스캔해 올리는 즉시 동의율 현황이 갱신됩니다.

05

전자+서면 병행 총회

elecVot 연계 · 하이브리드 집계

전자투표는 elecVot으로, 서면결의서는 omrAgent로 — 두 채널의 집계를 합산해 총회 전체 결과를 완성합니다.

06

공동주택·관리단 집회

집합건물법 · 공동주택관리법 서면결의

아파트 동별 대표자 선출, 집합건물 관리단 집회 등 정비사업 밖의 서면 투표도 동일한 흐름으로 판독·집계합니다.

사용 절차

양식 등록부터 Excel 보고까지 4단계

01

현장 등록

빈 결의서 양식 PDF 업로드 → 표 구조·기표 원 자동 감지, 감지 결과 이미지로 검수.

02

결의서 일괄 처리

스캔 PDF 폴더 선택 → 병렬 판독, 진행 바·로그로 실시간 현황 확인.

03

검토·보정

검토 필요 건만 원본 PDF 육안 확인 → 드롭다운 보정, 원본 판정·수정 시각 자동 기록.

04

Excel 보고

안건별 집계 + 원시데이터 Excel 다운로드. 수식 기반이라 수정 시 집계 자동 갱신.
